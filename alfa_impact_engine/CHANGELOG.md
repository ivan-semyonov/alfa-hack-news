# Изменения

## 1.0.0 — 23.10.2026

Полный локальный сценарий: вход, постоянные данные, CSV импорт, три отраслевых шаблона, PDF/OCR и страничный поиск, собственный ограниченный агент, лента и объяснение, вопросы по сохранённому контексту, feedback, мониторинг и экспорт. Настройки OpenAI-совместимого API с моделями ТЗ и переносимым AES-256-GCM. Два LLM-этапа с проверкой ссылок, без fallback. Добавлены проверки доступа, CSRF, SSRF, idempotency и durable лимитов. Новые интерфейс, Docker, документация, notices и релизная упаковка. 174 теста; 24/24 продуктовых сценария.

## 0.3.0 — 22.10.2026

Grounded extraction утверждений, дат, чисел и объектов; явно включаемый совместимый LLM-адаптер; старый синтетический proof API и CLI.

## 0.2.0 / 0.1.0

Синтетический граф, исходные контракты, таксономия, AI-утилиты участника 1 и детерминированная демонстрация.

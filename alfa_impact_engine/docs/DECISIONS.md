# Реестр решений

## ADR-001 · 22.10.2026 · Первый пакет Участника 1

**Проблема.** Архив 0.1 принимает уже структурированный Event, а зона product/solution/AI требует согласованных контрактов, проверяемых гипотез и интерфейса для текста новости. Фактические CSV, аналитика и доступ к LLM отсутствуют.

**Решение.** Добавить локальные AI-утилиты и отдельный текстовый адаптер `RULES_DEMO`, сохранив `/api/analyze`. Сначала проверить передачу источников, сохранение гипотез и отказ при отсутствии маршрута. Существующий граф не расширять вымышленными сведениями о компаниях.

**Проверка.** Одна новость для двух компаний даёт разные результаты; source spans совпадают с исходным текстом; ответ не может менять company/event scope или подставлять неизвестные evidence/path IDs; `NOT_FOUND` обязателен при отсутствии цитат банка. CLI экспортирует схемы и готовит сообщения без внешних вызовов.

**Ограничение.** Словарные признаки не являются извлечёнными фактами; все результаты текста требуют ручной проверки. Контракт инсайта пока имеет только режим `RULES_DEMO`. Структурная валидация не оценивает смысловую достоверность.

**Откат/замена.** Текстовые endpoints и фронт можно отключить независимо; исходный структурированный API работает без них. При подключении модели заменить normalizer и версионировать режим/ошибки, сохранив границы источников и гипотез.

## ADR-002 · 22.10.2026 · Цитируемые утверждения и явный адаптер извлечения

**Проблема.** Словарные метки 0.2 не позволяют проверить поля события, даты и величины. Совпадения в разных предложениях, отрицания и условия могут ошибочно допустить маршрут. Реального доступа к модели пока нет.

**Решение.** Ввести `ExtractionDraft/ExtractionResult` 0.3 с точными source spans, статусом `SOURCE_ASSERTION` и `NEEDS_REVIEW`; сохранить локальный режим по умолчанию. LLM подключается только явно через конфигурацию и `extraction_mode=LLM`, после чего ответ проходит валидацию структуры, цитат и alias-реестра. Ошибка возвращает 503 без скрытого fallback. Инсайт по графу остаётся детерминированным.

**Проверка.** Даты не получают выдуманную точку отсчёта; числа/единицы/периоды цитируются без пересчётов. Отрицание и условие блокируют простой маршрут; объект и действие проверяются в одном исходном фрагменте даже при объединении/обрезке цитаты моделью. HTTP-провайдер испытывается только через MockTransport, совместимость реального endpoint не объявляется.

**Ограничение.** Простые языковые фильтры не заменяют семантическую проверку. Структура и цитаты не доказывают истинность. Бюджет адаптера локален процессу и без тарифов не оценивает деньги. Полноценного агента, RAG, persistence и реальных профилей нет.

**Откат.** Режим RULES не требует конфигурации LLM. Исходный структурированный `/api/analyze` сохранён. Документ версии 0.2 остаётся историческим описанием; актуальный статус ведётся отдельно.

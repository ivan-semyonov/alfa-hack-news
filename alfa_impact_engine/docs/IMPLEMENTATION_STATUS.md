## Фактическая проверка

- `python -m pytest`: **174 passed**. Единственное предупреждение — deprecated alias BlockingPortal внутри Starlette TestClient/AnyIO; выполнение тестов успешно.
- `python -m scripts.evaluate_product`: **24/24**, RAG-абляция успешна; структурные цитаты валидны.
- `python -m scripts.evaluate_extraction`: **14/14**, 28 запусков, 194/194 source spans; это разработческий синтетический набор.
- `python scripts/check_vault.py`: шифрование и повторное открытие успешны без вывода ключей. Отдельные тесты переноса, неверного ключа, tenant AAD, повреждения и повторного ввода проходят.
- Реальный локальный `ALFA-consumption.pdf`: 4 страницы OCR, 14 фрагментов; дата 05.08.2026, цитаты страниц 1/3/2. Источник и результаты проверки исключены из публичной поставки.
- Браузер: демовход, новая новость о меди, вывод/путь, вопрос, кабинет admin в отдельной тестовой БД, сохранение фиктивного ключа при отключённой модели, настоящий PDF и просмотр страницы. Проверены раскладки 1440 и 390 пикселей.

## Что нужно для внешней приёмки

Пользователь вводит URL/ключ/технический ID разрешённой модели и запускает проверку/реальную новость. Предоставленные CSV проверяются отдельно на фактической схеме, объёме и семантике. Docker и PostgreSQL требуют исполнения в доступной среде. Производственное размещение требует эксплуатационной приёмки и независимой оценки качества. GitHub/доступ жюри выполняются только после указания репозитория и адресата; требование из документа само по себе не является командой на публикацию.
